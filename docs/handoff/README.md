# Handoff

handoff 문서는 다음 agent/session이 가장 먼저 읽는 문서다.

현재 phase, 완료된 작업, 다음 작업, 주의사항을 짧게 기록한다. 긴 설계 설명은 `docs/specs/`, `docs/adrs/`, `docs/plans/`, `docs/runbooks/`로 분리하고 handoff에는 링크와 요약만 둔다.

## 현재 문서

- `CURRENT_HANDOFF.md`

## 작성 규칙

- 현재 상태를 먼저 쓴다.
- 다음 작업 후보를 작은 단위로 쓴다.
- 건드리지 말아야 할 파일/폴더를 명시한다.
- 테스트 명령을 적는다.
- Notion은 요약/인덱스만 담당한다는 원칙을 반복해서 명시한다.
