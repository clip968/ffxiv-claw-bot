# v0.5-01 Plan: Spec and Plan

## Status

**Completed 2026-05-16**

## Goal

v0.5 Source Processing Pipeline의 범위, non-goals, 실행 경계, task breakdown을 문서로 고정한다.

이번 task는 실제 구현보다 먼저, v0.5에서 무엇을 만들고 무엇을 만들지 않을지를 명확히 하는 작업이다.

## Background

현재 v0.4에서는 Local Storage ingest, rebuild, FTS, graph, Notion status payload 관련 도구가 분리되어 있다.

문제는 OpenClaw가 여러 도구를 매번 수동 순서로 호출해야 한다는 점이다.

v0.5에서는 이 흐름을 다음 구조로 고정한다.

OpenClaw Skill Layer
- 사용자 요청 해석
- source_type 판단
- category 판단
- title/body/url/local_path 구성
- process_source.py 호출
- 결과 JSON 해석
- Notion update 수행

Repo Execution Layer
- process_source.py
- ingest
- rebuild
- FTS
- graph
- Notion update payload 생성
- JSON result 출력

## Scope

이번 task에서 수행할 일:

1. v0.5 통합 spec 작성
2. v0.5 전체 plan 작성
3. v0.5 task breakdown 고정
4. v0.4 문서와 충돌 여부 확인
5. handoff 문서에 v0.5 시작 상태 기록
