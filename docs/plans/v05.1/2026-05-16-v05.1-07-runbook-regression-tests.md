## Key Decisions

- Regression tests should check stable meaning, not fragile long paragraphs.
- Keep tests local and deterministic; no external services.
- This task enforces docs that prevent operational mistakes, not code behavior.

## Implementation Notes

- Prefer a small helper that reads `docs/runbooks/process-source.md` once and asserts required phrases.
- Keep test names explicit so failures identify the missing boundary.
