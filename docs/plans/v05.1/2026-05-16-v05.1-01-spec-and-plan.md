## Key Decisions

- v05.1은 새 source type 확장이 아니라 hardening release다.
- 원본 implementation plan의 `pytest` 예시는 repo 표준이 아니므로 v05.1 task plan에서는 `python -m unittest ...`로 보정한다.
- `--source-file` 중심 흐름은 현재 v0.5 contract와 맞지 않으므로 공식 실행 예시는 `--source-type markdown_file --local-path` 또는 `--source-type url --url`을 사용한다.
- `process_source.py`는 Notion API를 직접 호출하지 않고 `notion_update` payload만 생성한다.
