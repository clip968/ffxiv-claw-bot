## Goal

정상 source processing의 공식 entrypoint가 `tools/process_source.py`임을 문서로 고정하고, helper module 직접 호출 혼동을 줄인다.

## Scope

- `process_source.py` official entrypoint 문서화
- `markdown_file`은 `process_source.py --local-path`를 사용해야 함을 문서화
- `ingest_local.py --body <file path>` misuse와 실패 이유 문서화
- `local_rebuild.py`는 normal workflow에서 library-only module임을 문서화
- `status_notification.py`는 Notion write CLI가 아니라 payload builder임을 문서화
- `process_source.py`는 `notion_update` payload만 생성하고 Notion API를 직접 호출하지 않음을 문서화
- v05.1 test commands 문서화
- handoff에 v05.1 진행 상태 기록

Out of scope:

- code behavior 변경
- optional debug CLI 구현
- Notion API apply 구현
- v0.6 automation loop 문서화
