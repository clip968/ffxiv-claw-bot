## Goal

Lodestone news/detail/patch-note page에서 article body를 안정적으로 추출하는 domain-specific extractor를 구현한다.

## Scope

- `tools/extractors/` package 추가
- Lodestone URL 판별 함수 추가
- `.news__detail__wrapper` 우선 article extraction 구현
- title/body/extractor metadata 반환
- clear extraction error 추가
- whitespace normalization
- script/style/nav/footer/share UI noise 제거

Out of scope:

- network fetch 구현
- `fetch_url.py` 라우팅
- `process_source.py` action metadata
- crawler 또는 여러 URL 자동 순회
- LLM 기반 요약 품질 개선

## Key Decisions

- Keep the extractor deterministic and dependency-light.
- Prefer existing local HTML utilities if they fit; do not introduce new parser dependencies unless a spec/plan is updated first.
- Do not make this extractor responsible for Local Storage, rebuild, or Notion payloads.

## Implementation Notes

- Implemented a dependency-light extractor with an optional BeautifulSoup path and a standard-library `HTMLParser` fallback.
- The extractor only returns title/body/extractor metadata; it does not fetch URLs, ingest Local Storage, rebuild, or build Notion payloads.
- `fetch_url.py` routing and `process_source.py` action metadata remain owned by v05.1-04 and v05.1-05.
