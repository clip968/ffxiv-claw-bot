## Goal

Lodestone 7.5 패치노트 계열 HTML에서 본문 추출 문제가 재발하지 않도록 fixture와 red tests를 먼저 추가한다.

## Scope

- 작은 Lodestone-like HTML fixture 추가
- `.news__detail__wrapper` article container 기반 추출 기대값 테스트
- navigation/footer/share/script/style noise 제외 테스트
- title 추출 테스트
- 비어 있는 article body error 테스트

Out of scope:

- extractor 구현
- `fetch_url.py` 라우팅
- `process_source.py` 변경
- 실제 Lodestone 네트워크 요청
- crawler, scheduler, sitemap traversal

## Red Test

- File: `tests/test_v05_1_lodestone_extractor.py`
- Fixture: `tests/fixtures/lodestone_patch_7_5.html`
- Implementation target: `tools/extractors/lodestone.py`
- Current red reason: Lodestone-specific extractor module does not exist yet.

Contracts fixed by the tests:

- `is_lodestone_url()` recognizes official Lodestone URLs.
- `extract_lodestone_article()` uses `.news__detail__wrapper`.
- Extracted body includes patch note content.
- Extracted body excludes navigation, footer, script, style, and share UI noise.
- Empty or unusable article content fails clearly.

## Key Decisions

- The fixture should be deterministic and local; tests must not fetch Lodestone over the network.
- The tests should assert meaningful included/excluded phrases rather than snapshotting the whole body.
- Test module name uses `v05_1` because `.` is not safe in importable Python module names.

## Implementation Notes

- Do not implement the extractor in this task.
- Do not use `pytest`; this repo standard is `unittest`.
