- export 로직을 rebuild CLI에서 호출 가능

## Key Decisions

- `nodes.json` 형식: `[{"id", "type", "name", "canonical_name", "aliases", "properties"}]`
- `edges.json` 형식: `[{"id", "source", "target", "relation", "source_id", "confidence", "properties"}]`
- `domain_graph.json` 형식: `{"metadata": {"schema_version": "v08", "generated_at", "node_count", "edge_count"}, "nodes", "edges"}`
- `entity_index.json` 형식: `{"alias_lowercase": "node_id"}`. 모든 alias를 lowercase로 저장.
- JSON 출력은 `json.dumps(ensure_ascii=False, indent=2, sort_keys=True)`로 deterministic하게 생성.
