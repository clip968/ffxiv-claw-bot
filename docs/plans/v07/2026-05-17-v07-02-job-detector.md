## Goal

사용자 질문에서 FFXIV 직업명을 감지하는 `detect_job()` 함수를 구현한다. v06에서 만든 job catalog를 재사용한다.

## Scope

- `src/query/job_detector.py` 추가
- 한국어 풀네임 alias 매칭 (건브레이커 → gunbreaker)
- 한국어 약어 alias 매칭 (건브 → gunbreaker)
- 영어 abbreviation 매칭 (GNB → gunbreaker)
- 영어 full name 매칭 (Black Mage → black_mage)
- 직업 없는 질문은 `None` 반환
- longest alias match wins

Out of scope:

- patch range parsing (v07-03)
- intent detection (v07-04)
- 새로운 alias 추가 (기존 job catalog 그대로 사용)

## Key Decisions

- `src.derived_wiki.job_catalog.JOB_CATALOG`을 그대로 재사용한다. 별도 catalog를 만들지 않는다.
- ASCII alias는 word boundary matching (`(?<![a-z0-9])...(![a-z0-9])`)을 사용한다.
- 한국어 alias는 substring matching (`alias in text`)을 사용한다.
- 여러 alias가 매칭될 때 가장 긴 alias가 우선한다.
